# 企业流程审批系统 — 部署环境确认清单

> 用途：请 IT 协助确认服务器部署环境，确认后我们据此给出具体部署方案。
> 系统规模：约 100 人同时在线，内网使用。

---

## 一、系统简介

| 项 | 说明 |
|----|------|
| 系统 | 企业流程审批系统（流程发起 / 文件上传 / 校验 / 审批 / PDF 签名） |
| 部署位置 | 公司内部服务器（内网访问，不对外暴露） |
| 用户规模 | 约 100 人同时在线 |
| 技术栈 | 后端 FastAPI（Python 3.10+），前端 Vue3，数据库 MySQL 8，缓存 Redis 6，PDF 转换 LibreOffice，反向代理 Nginx（可选） |

---

## 二、需要确认的服务器信息（5 项）

| # | 确认项 | 需要提供的信息 | 为什么重要 |
|---|--------|----------------|-----------|
| 1 | **操作系统** | 服务器系统及版本（如 Ubuntu 22.04 / Windows Server 2019） | 决定进程托管方式：Linux 用 systemd，Windows 用计划任务/服务 |
| 2 | **服务器规格** | CPU 核数 / 内存 / 磁盘剩余空间 | 100 人规模建议 4 核 8G + 50GB 可用磁盘（归档文件持续增长） |
| 3 | **软件依赖** | 是否已装 MySQL 8、Redis 6、LibreOffice；版本分别是？还是需要全新安装 | 系统硬依赖这三样，缺一不可 |
| 4 | **内网访问方式** | 服务器内网 IP 或内部域名 | 用户浏览器通过它访问系统，同时写入系统 CORS 配置 |
| 5 | **运维权限** | 谁能安装软件（root / 管理员权限）、谁能管理数据备份 | 决定安装方式与备份落点 |

## 三、软件依赖清单

| 软件 | 版本 | 用途 | 是否已具备 |
|------|------|------|-----------|
| Python | 3.10+ | 后端运行 | ☐ 是 / ☐ 需安装 |

---

## 四、部署方式选项

- **Linux 服务器**：systemd 托管两个后台进程（API + PDF 转换 Worker），开机自启、崩溃自动重启。
- **Windows Server**：以计划任务或 Windows 服务方式托管，同样双进程。
- 若上述软件尚未安装，请确认 IT 可提供安装权限（root / 管理员账号）。

---

## 五、网络与安全

| 项 | 要求 |
|----|------|
| 访问地址 | 内网 IP 或内部域名（浏览器访问入口） |
| 端口 | 对外只开 80/443（或 8000）；MySQL 3306、Redis 6379 仅本机监听，不对内网开放 |
| HTTPS | 可选。内网信任环境可先 HTTP，后续需加密可用自签证书或公司 CA |
| 数据安全 | 系统本身无公网暴露面，数据存储于公司内网服务器 |
