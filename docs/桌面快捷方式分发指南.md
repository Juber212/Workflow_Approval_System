# 桌面快捷方式分发指南

> 用途：系统部署完成后，让员工电脑桌面都有「智展研究院设计开发管理系统」快捷方式，双击直接打开浏览器进入系统。
> 适用环境：员工电脑为 Windows（Win10/11）。系统访问地址部署后确定，下文用 `http://192.168.1.50` 作示例，**使用时替换为实际地址**。

---

## 0. 前置条件

| 项 | 说明 |
|----|------|
| 系统已部署 | 后端 + 前端已上线，浏览器能打开登录页 |
| 访问地址 | `http://服务器内网IP[:端口]`（如 Nginx 配 80 则无端口） |
| 员工电脑 | Windows，能访问系统地址（同一内网） |

---

## 1. 一键创建脚本（推荐，无域环境也能用）

给员工一个 `.bat` 脚本，双击运行即自动在桌面创建快捷方式。

**`创建系统快捷方式.bat`**（内容见附录，改好地址后分发）：

```bat
@echo off
chcp 65001 >nul
set SYS_URL=http://192.168.1.50
set SHORTCUT_NAME=智展研究院设计开发管理系统
set DESKTOP=%USERPROFILE%\Desktop

echo [InternetShortcut] > "%DESKTOP%\%SHORTCUT_NAME%.url"
echo URL=%SYS_URL% >> "%DESKTOP%\%SHORTCUT_NAME%.url"
echo IconFile=%SystemRoot%\System32\imageres.dll >> "%DESKTOP%\%SHORTCUT_NAME%.url"
echo IconIndex=15 >> "%DESKTOP%\%SHORTCUT_NAME%.url"

echo 已在桌面创建快捷方式：%SHORTCUT_NAME%
pause
```

员工操作：双击 → 看到「已在桌面创建快捷方式」→ 桌面出现带图标的快捷方式 → 双击打开系统登录页。

> 说明：脚本创建的是 `.url` 快捷方式，双击用系统默认浏览器打开；图标取系统库（imageres.dll）里的浏览器图标，可自行改 `IconIndex` 换样式。

---

## 2. 批量分发（无域环境）

1. 把改好地址的 `创建系统快捷方式.bat` 放到**内网共享文件夹**（或服务器可下载目录）。
2. 邮件 / 内部即时通讯发通知，附操作步骤：双击 → 回车。
3. 员工各自双击一次即完成。

> 优点：零成本、一次分发永久生效（电脑重装系统后重跑一遍即可）。

---

## 3. 域环境批量推送（公司有 Active Directory 时）

如果公司有域环境（AD），管理员可通过**组策略（GPO）**自动给所有域内电脑桌面推送快捷方式，员工无需任何操作：

1. 打开「组策略管理」（GPMC）→ 新建 GPO（如「系统桌面快捷方式」）。
2. 编辑 GPO → **用户配置 → 首选项 → Windows 设置 → 快捷方式** → 右键新建 → **快捷方式**。
3. 配置：
   - 操作：创建
   - 名称：`智展研究院设计开发管理系统.url`
   - 目标：`%DesktopDir%\智展研究院设计开发管理系统.url`
   - 目标类型：URL
   - URL：`http://192.168.1.50`（实际地址）
   - 图标：选一个（可留默认）
4. 将 GPO 链接到**员工电脑所在的组织单元（OU）**，等待组策略刷新（约 90 分钟，或员工重启）。

> 需要公司有域环境 + 管理员权限；无域环境请用第 1/2 节方式。

---

## 4. 手动创建（兜底，单台电脑）

1. 用浏览器打开系统地址。
2. 点地址栏左侧的锁/地球图标，按住拖到桌面 → 自动生成带图标快捷方式。
   （或：浏览器菜单 → 更多工具 → 创建快捷方式）

---

## 附录：脚本源码

```bat
@echo off
chcp 65001 >nul
rem ====== 部署后修改这两处 ======
set SYS_URL=http://192.168.1.50
set SHORTCUT_NAME=智展研究院设计开发管理系统
rem ============================

set DESKTOP=%USERPROFILE%\Desktop
if not exist "%DESKTOP%" set DESKTOP=%USERPROFILE%\OneDrive\Desktop

echo [InternetShortcut] > "%DESKTOP%\%SHORTCUT_NAME%.url"
echo URL=%SYS_URL% >> "%DESKTOP%\%SHORTCUT_NAME%.url"
echo IconFile=%SystemRoot%\System32\imageres.dll >> "%DESKTOP%\%SHORTCUT_NAME%.url"
echo IconIndex=15 >> "%DESKTOP%\%SHORTCUT_NAME%.url"

echo 已在桌面创建快捷方式：%SHORTCUT_NAME%
pause
```

> 备注：脚本兼容 OneDrive 桌面重定向（`OneDrive\Desktop`）。
> 若员工电脑浏览器默认非 Chrome/Edge，双击 `.url` 仍会用系统默认浏览器打开。
