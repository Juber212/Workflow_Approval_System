# 桌面快捷方式分发指南

> 用途：系统部署完成后，让员工电脑桌面都有「智展研究院设计开发管理系统」快捷方式，双击直接打开浏览器进入系统。
> 适用环境：员工电脑为 Windows（Win10/11）。系统访问地址部署后确定，下文用 `http://192.168.1.50` 作示例，**使用时替换为实际地址**。

---

## 为什么用 .lnk 而不是 .url

桌面快捷方式有两种：
- **`.url`（InternetShortcut）**：简单文本文件，但 Windows 对 http 地址的 `.url` **会强制显示默认浏览器图标**，`IconFile` 字段常被忽略 → 图标不可控。
- **`.lnk`（标准快捷方式）**：图标字段由 Windows 可靠生效，能显示系统 Logo。本方案用 `.lnk`。

> 本方案通过 PowerShell 创建 `.lnk`，`TargetPath` 直接填系统地址 URL，双击由 Windows **shell 原生用默认浏览器**打开（与 `.url` 的 URL 打开同样可靠），图标由 `IconLocation` 指定为系统 Logo。

---

## 0. 前置条件

| 项 | 说明 |
|----|------|
| 系统已部署 | 后端 + 前端已上线，浏览器能打开登录页 |
| 访问地址 | `http://服务器内网IP[:端口]`（如 Nginx 配 80 则无端口） |
| 员工电脑 | Windows，能访问系统地址（同一内网） |

---

## 1. 一键创建脚本（推荐，无域环境也能用）

**共 3 个文件，放同一目录分发**：
`创建系统快捷方式.bat` + `create-shortcut.ps1` + `logo.ico`

**`创建系统快捷方式.bat`**（双击入口，改好地址后分发）：

```bat
@echo off
set SYS_URL=http://192.168.1.50
powershell -NoProfile -ExecutionPolicy Bypass -File "%~dp0create-shortcut.ps1" -Url "%SYS_URL%"
echo.
pause
```

**`create-shortcut.ps1`**（创建快捷方式本体，与 bat 同目录）：

```powershell
param([string]$Url = "http://localhost:8090")
$Name = "智展研究院设计开发管理系统"
$Dir = Split-Path -Parent $MyInvocation.MyCommand.Path
$Icon = Join-Path $Dir "logo.ico"
$Desktop = [Environment]::GetFolderPath("Desktop")
$lnkPath = Join-Path $Desktop "$Name.lnk"
$ws = New-Object -ComObject WScript.Shell
$lnk = $ws.CreateShortcut($lnkPath)
$lnk.TargetPath = $Url
$lnk.IconLocation = "$Icon,0"
$lnk.Description = $Name
$lnk.Save()
Write-Host "已在桌面创建快捷方式: $Name.lnk"
```

员工操作：双击 `创建系统快捷方式.bat` → 桌面出现带系统 Logo 图标的快捷方式 → 双击打开系统登录页。

> 说明：图标使用**系统 Logo**（`logo.ico`），脚本用 `%~dp0` 自动定位同目录图标，**分发时 3 个文件必须同目录**，缺一不可。

---

## 2. 批量分发（无域环境）

1. 把改好地址的 `创建系统快捷方式.bat`、`create-shortcut.ps1`、`logo.ico` **3 个文件一起**放到**内网共享文件夹**（或服务器可下载目录），保持同一目录。
2. 邮件 / 内部即时通讯发通知，附操作步骤：双击 → 回车。
3. 员工各自双击一次即完成。

> 优点：零成本、一次分发永久生效（电脑重装系统后重跑一遍即可）。

---

## 3. 域环境批量推送（公司有 Active Directory 时）

如果公司有域环境（AD），管理员可通过**组策略（GPO）**自动给所有域内电脑桌面推送快捷方式：

1. 打开「组策略管理」（GPMC）→ 新建 GPO（如「系统桌面快捷方式」）。
2. 编辑 GPO → **用户配置 → 首选项 → Windows 设置 → 快捷方式** → 右键新建 → **快捷方式**。
3. 配置：
   - 操作：创建
   - 名称：`智展研究院设计开发管理系统.url`
   - 目标：`%DesktopDir%\智展研究院设计开发管理系统.url`
   - 目标类型：URL
   - URL：`http://192.168.1.50`（实际地址）
   - 图标：建议在共享路径放 `logo.ico`，图标路径填 `\\内网共享\系统\logo.ico`
4. 将 GPO 链接到**员工电脑所在的组织单元（OU）**，等待组策略刷新（约 90 分钟，或员工重启）。

> 需要公司有域环境 + 管理员权限；无域环境请用第 1/2 节方式。
> 注意：GPO 推 `.url` 时图标可能仍被浏览器覆盖，若要求严格可用 GPO「启动脚本」跑第 1 节的 ps1 方式创建 `.lnk`。

---

## 4. 手动创建（兜底，单台电脑）

1. 双击 `创建系统快捷方式.bat`（同目录放好 3 个文件）。
2. 或：用浏览器打开系统地址 → 点地址栏左侧图标拖到桌面（此方式图标是浏览器默认，非系统 Logo）。

## 附录：完整文件清单

| 文件 | 用途 |
|------|------|
| `创建系统快捷方式.bat` | 员工双击入口（GBK/CRLF，中文注释不乱码） |
| `create-shortcut.ps1` | PowerShell 创建 `.lnk`（UTF-8 BOM，中文名正常） |
| `logo.ico` | 系统 Logo 图标（favicon.svg 转的多尺寸透明 ICO） |

> 备注：
> - `bat` 只设地址并调 ps1，部署后**只改 bat 里 `SYS_URL` 一行**即可。
> - ps1 需 **UTF-8 BOM** 编码（PowerShell 5 读中文才正常）；bat 需 **GBK + CRLF**（Windows 中文 cmd 标准）。仓库里已是正确编码，勿用记事本「另存为」改编码。
> - 兼容 OneDrive 桌面重定向（`[Environment]::GetFolderPath("Desktop")` 自动适配）。
